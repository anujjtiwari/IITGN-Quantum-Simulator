1. The Cryptographic Hash

The immutable digital fingerprint.

Hashing is the process of converting data of any size (text, file, transaction, etc.) into a fixed-length string using a mathematical algorithm called a hash function. The output is called a hash or digest. A Hash function (like SHA-256) is the mathematical engine of blockchain. It converts input data of any size into a fixed-size string of 64 characters.

The Avalanche Effect: A microscopic change in input results in a catastrophic change in output. This makes tampering instantly detectable.

What Exactly Is a Block?

The fundamental building unit of a blockchain.

A block is a structured container of data that represents a snapshot of the system state at a specific moment in time.

Instead of storing transactions randomly, blockchains group them into blocks. This makes the system:

  • ✔ Easier to verify
  • ✔ Cryptographically secure
  • ✔ Tamper-evident
  • ✔ Chronologically ordered
Key idea:
A blockchain is not secured by trust — it is secured by the mathematical structure of its blocks.

Why Blocks Make Blockchain Secure

Immutability

Changing any data inside a block completely changes its hash.

Chain Reaction

Since each block stores the previous hash, one change breaks the entire chain.

Verifiability

Anyone can recompute hashes and verify integrity without trust.

2. Mining & The Nonce

Proof of Work securing the block.

A block contains fixed Data. To make a block secure, the network requires its Hash to meet a specific condition (e.g., start with `0000`).

Since we can't change the Data, we add a "dummy" field called the Nonce (Number used ONCE). Mining is the computational process of rapidly guessing different Nonce values until the resulting block hash meets the target condition.

4. Distributed Consensus

Peer-to-Peer network security.

The blockchain doesn't exist on one server. It is replicated across thousands of network nodes (Peers).

Consensus Rule: The majority rules. If one peer's copy of the chain has been tampered with, its hash won't match the others. The network automatically rejects the corrupted copy.
